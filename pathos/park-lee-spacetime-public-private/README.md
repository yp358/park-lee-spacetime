# Park-Lee Spacetime: Public & Private Domains

This directory contains dual mirrors of the `park-lee-spacetime` architecture:

- **`public/`**: Public manifestation and open domain copy of `park-lee-spacetime`.
- **`private/`**: Private manifestation and protected domain copy of `park-lee-spacetime`.

Both `public/` and `private/` instantiate identical four-tier ontological structures (`creos`, `ethos`, `logos`, `pathos`).
